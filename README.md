# Sporchut

Portal esportivo moderno em português.

## Stack
- React + TypeScript
- Vite
- CSS responsivo

## Estrutura
- `src/components` — componentes reutilizáveis
- `src/pages` — páginas do portal
- `src/data` — dados iniciais
- `src/services` — integração futura com APIs esportivas e notícias
- `public` — arquivos públicos
